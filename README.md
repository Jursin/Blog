# Blog

网站使用 [VitePress](https://vitepress.dev/) 构建生成。

## 安装

```sh
pnpm i
```

## 使用

```sh
# 启动开发服务
pnpm dev
# 构建生产包
pnpm build
# 本地预览生产服务
pnpm preview
```
